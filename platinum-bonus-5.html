Tools ini memiliki dua mode yang bisa Anda pilih sesuai kebutuhan:

1. Mode Manual (Custom)

Gunakan mode ini jika Anda ingin hasil yang spesifik.

  • Input Topik Produk (Misal: Ebook Diet)
  • Pilih Platform (Misal: PDF / Instagram)
  • Pilih Rasio Ukuran (Misal: A4 atau 1080x1080)
  • Hasil: Tools akan membuatkan konten lengkap beserta layout dan captionnya.

2. Mode Matic (Otomatis)

Gunakan mode ini jika Anda ingin hasil instan tanpa mikir.

  • Cukup klik tombol "Buatkan Produk Digital"
  • Hasil: Tools akan langsung mencari ide tren terbaru dan membuatkan produk digital lengkap untuk Anda jual.
